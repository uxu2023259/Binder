一款面向 Paper / Leaves 的高安全灵魂绑定插件：玩家可通过 GUI 绑定重要物品，实时追踪背包、容器、掉落物、展示框、盔甲架等位置，并在召回前先移除真实原物品，尽量避免复制与误判。支持 Vault 费用、CoreProtect 线索、SQLite 数据库、自动备份、重复物隔离和中文可配置文本。

## 插件页详细介绍

### ✦ SoulBinder 灵魂契约是什么？

SoulBinder 灵魂契约是一款专为生存服、RPG 服、经济服和高价值道具服务器准备的物品安全插件。玩家可以把重要装备、纪念道具或活动奖励绑定到自己名下，并通过 `/bind` 打开图形菜单进行查看、体检、追踪和召回。

插件的核心目标不是“凭空补发物品”，而是尽可能确认真实原物品的位置，并在召回时先移除原物品再发还给玩家，从流程上降低复制物品、错误补偿和道具流转失控的风险。

### ✦ 主要卖点

- **全 GUI 操作**：玩家与管理员功能均集中在 `/bind` 菜单中，无需记复杂子命令。
- **真实位置追踪**：支持玩家背包、鼠标、掉落物、方块容器、实体容器、末影箱、铁砧输入槽、临时界面、潜影盒/收纳袋内部、盔甲架、物品展示框和物品展示实体等位置。
- **安全召回机制**：召回前优先定位并移除真实原物品，避免直接生成副本。
- **重复物隔离**：检测到重复绑定 UUID 时，会将多余实例写入隔离仓库，降低复制风险。
- **不可离包保护**：可阻止绑定物被丢弃、放入容器、放到展示框/盔甲架或随死亡掉落。
- **个人安全体检**：玩家可查看自己的绑定物状态分布，一键扫描并定位最需要处理的物品。
- **管理员维护面板**：支持玩家绑定物管理、全服安全扫描、数据库检查点、手动备份、隔离仓库查看、配置重载等。
- **CoreProtect 辅助线索**：可读取容器记录作为候选位置，最终仍以真实库存中的绑定 UUID 为准。
- **Vault 经济支持**：可配置绑定、解除、普通召回和丢失召回费用。
- **SQLite 持久化与备份**：绑定数据保存到本地 SQLite，支持自动备份、事件备份和手动维护备份。
- **中文发布级体验**：提示、日志、配置说明和 GUI 文本均为中文，`messages.yml` 可自定义品牌、标题、按钮和 Lore 模板。

### ✦ 适合哪些服务器？

- 担心玩家重要物品被误丢、误放、误拿的生存服。
- 有高价值装备、抽奖道具、充值道具或活动纪念物的服务器。
- 希望减少“物品丢失补偿纠纷”的服务器。
- 希望在物品召回功能中尽量防止复制漏洞的服务器。
- 需要中文 GUI、中文日志和低学习成本的服务器。

### ✦ 命令与权限

| 内容 | 说明 |
| --- | --- |
| `/bind` | 打开灵魂绑定主菜单 |
| `/soulbind` | `/bind` 别名 |
| `/sbind` | `/bind` 别名 |
| `bind.use` | 允许使用玩家功能，默认所有玩家 |
| `bind.admin` | 允许管理所有玩家绑定物，默认 OP |

### ✦ 依赖与兼容

- **服务端**：Paper / Leaves `1.20.4 - 1.21.11`
- **Java**：Java 17+
- **可选依赖**：Vault + 经济插件
- **可选依赖**：CoreProtect

### ✦ 安装方法

1. 下载插件 jar 文件。
2. 放入服务器 `plugins` 文件夹。
3. 重启服务器。
4. 根据需要修改 `plugins/Binder/config.yml` 和 `plugins/Binder/messages.yml`。
5. 玩家输入 `/bind` 开始使用。

### ✦ 配置亮点

- 可设置每名玩家最大绑定数量。
- 可设置绑定费用、解除费用、普通召回费用、丢失召回费用。
- 可设置召回冷却。
- 可开启材料白名单或黑名单。
- 可配置自动轻量扫描频率、每轮扫描数量和时间预算。
- 可配置数据库备份策略和保留数量。
- 可自定义 GUI 标题、按钮文本、消息前缀和绑定 Lore。

### ✦ 安全说明

插件不会在无法确认原物品已移除时随意生成副本。若物品处于临时界面、同步流程或位置刚发生变化，召回可能会提示重新扫描或稍后再试。这是为了优先保护服务器物品经济安全。
