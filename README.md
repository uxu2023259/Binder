# Binder 灵魂绑定插件

Binder 是一款面向 Paper / Leaves `1.20.4 - 1.21.11` 的灵魂绑定物品插件，专注于安全绑定、实时追踪和可靠召回重要物品。插件在召回前会优先确认并移除真实原物品，尽量避免复制物品、误判丢失和异常流转。

## 主要特性

- 通过 `/bind` 打开多页 GUI，完成查看、召回和管理。
- GUI 已按发布级观感优化，包含统一标题、功能分区、状态徽标、导航按钮和边框提示。
- GUI 内置刷新当前页、重新扫描位置和聊天输出详情，便于玩家自助排查物品位置。
- 主菜单内置“新手指南与安全说明”，用三步说明帮助玩家快速上手。
- 玩家第一次打开空绑定物库时，可直接在列表页点击“立即绑定主手物品”，不用来回切菜单。
- 绑定成功后会自动打开绑定物库，让玩家立即看到刚绑定的物品与状态。
- 列表和详情会显示“推荐操作”、费用、背包空位要求等提示，减少误点和不确定感。
- 绑定物列表会在物品名称前显示状态符号，玩家无需逐行阅读 Lore 也能快速判断是否丢失、掉落、在容器或被他人持有。
- 玩家主菜单内置“我的安全体检”，可查看个人绑定物状态分布、一键扫描全部绑定物并输出聊天摘要。
- 体检页支持一键打开最需要处理的绑定物详情，减少玩家在列表中翻找问题物品的时间。
- 列表、确认页和管理员详情已补充清晰操作提示，减少误点和误判。
- 插件启用和停用时会在控制台输出清晰的中文状态面板，方便服主确认版本、集成和扫描状态。
- GUI 内一键绑定主手中的单个物品。
- 支持追踪玩家背包、鼠标、掉落物、方块容器、实体容器、末影箱、铁砧输入槽、临时界面、物品形态收纳容器、盔甲架、物品展示框和物品展示实体。
- 允许绑定物放入更多可交互位置；会扫描真实绑定 UUID 与收纳容器内容，召回时先移除原物品，避免复制。
- 不可离包会递归检查潜影盒、收纳袋等物品内容，避免把锁定绑定物藏入收纳物后绕过限制。
- 防呆保护会阻止把已经包含绑定物的收纳容器再次绑定为外层绑定物，并拦截确认页过快连点。
- 解除绑定前会先处理重复 UUID，避免把复制出来的异常物品解除绑定后“洗白”。
- 解除绑定有付费配置时，会先完成费用检查，再执行隔离和解除，避免扣费失败时产生额外副作用。
- 玩家死亡时会保护包含不可离包绑定物的收纳物，复活后尝试返还，背包满时会安全掉落在脚下并继续追踪。
- 放置包含非锁定绑定物的收纳方块后，会立即刷新方块容器位置，减少短时间位置显示误差。
- 召回流程遵循“先移除真实原物品，再发还”的安全机制。
- 可接入 CoreProtect，将容器记录作为候选线索；最终仍以真实库存中的绑定 UUID 为准。
- 可接入 Vault 经济，支持配置绑定、解除绑定、普通召回和丢失召回费用。
- 支持配置召回冷却时间。
- 支持绑定材料白名单/黑名单，便于服主禁止管理类或高风险物品被绑定。
- 绑定记录已改用本地 SQLite 数据库保存；首次启用数据库版时会自动迁移旧 `data.yml`。
- 支持绑定物提醒：物品落地、被其他玩家捡起、被其他玩家操作时，会提醒在线绑定者。
- 提醒会递归识别潜影盒、收纳袋等物品内部的绑定物，避免外层收纳物被操作时漏提醒。
- 玩家可在 `/bind` 主菜单中单独开启或关闭自己的绑定物提醒。
- 熔炉、酿造台、发射器、投掷器和合成器不会被粗暴拦截；绑定物被机器消耗或转化时会先标记丢失，并等待后续真实扫描校正位置。
- 容器被破坏或爆炸时，会优先弹出包含绑定物的物品并继续追踪，降低被原版掉落流程吞掉的风险。
- 自动扫描采用轻量分批校验已知位置，降低长期主线程占用；管理员维护仍可手动执行深度全服扫描。
- 检测到重复绑定 UUID 时，会将多余实例隔离到 `quarantine.yml`，降低复制风险。
- 管理员 GUI 内置插件统计和“一键维护与备份”，可合并执行全服扫描、数据库检查点和手动备份。
- 管理员 GUI 内置 SQLite 数据库状态与安全检查点维护，便于发布后排查备份和落盘状态。
- `messages.yml` 支持客制化前缀、GUI 标题、按钮文本和绑定 Lore 模板。
- 管理员功能已整合到 GUI，可查看、扫描、召回、修改绑定者、解除绑定、查看隔离仓库并重载配置。

## 依赖

- 必需：Paper / Leaves `1.20.4 - 1.21.11` 服务端
- 可选：Vault + 经济插件
- 可选：CoreProtect

## 常用命令

Binder 从 `1.0.23` 开始停用子命令，所有功能均在 GUI 中完成。

- `/bind` 打开灵魂绑定主菜单
- `/soulbind` 打开灵魂绑定主菜单
- `/sbind` 打开灵魂绑定主菜单

### GUI 内玩家功能

- 绑定主手物品
- 查看新手指南与安全说明
- 查看多页绑定物列表
- 安全召回绑定物
- 查看绑定物详情
- 刷新绑定物列表
- 在详情页重新扫描真实位置
- 在详情页将绑定物详情输出到聊天栏
- 切换不可离包
- 二次确认解除绑定
- 查看当前费用、绑定上限、召回冷却和材料规则
- 打开“我的安全体检”查看位置分布、安全建议，一键扫描全部绑定物并输出问题物品清单
- 在“我的安全体检”中一键打开最需要处理的绑定物详情
- 开启或关闭自己的绑定物提醒

### GUI 内管理员功能

- 选择玩家并管理其绑定物
- 刷新玩家列表、玩家绑定物列表、统计面板和隔离仓库
- 管理员安全召回
- 重新扫描并刷新真实位置
- 将绑定物详情输出到聊天栏，便于审计和故障排查
- 切换不可离包
- 修改绑定者
- 二次确认解除绑定
- 查看重复物隔离仓库
- 查看插件统计
- 查看数据库状态并执行 SQLite 安全检查点
- 一键维护与备份：执行全服安全扫描、SQLite 安全检查点，并备份数据到 `backups` 文件夹
- 重载配置、消息和插件集成

## 权限

- `bind.use`：允许打开灵魂绑定 GUI 并使用玩家功能，默认所有玩家。
- `bind.admin`：允许通过 GUI 管理所有玩家的灵魂绑定物，默认 OP，并自动包含 `bind.use`。

## 配置文件

- `config.yml`：绑定上限、数据库文件、绑定材料白名单/黑名单、经济费用、召回冷却、绑定物提醒、CoreProtect 和音效配置。
- `messages.yml`：前缀、GUI 标题、按钮文本和 Lore 模板。
- `binder.db`：SQLite 绑定记录数据库，文件名可在 `config.yml` 的 `database.sqlite-file` 修改。
- `data.yml`：旧版绑定记录文件；数据库为空时会自动迁移，迁移后旧文件会保留作为人工备份。
- `quarantine.yml`：重复物隔离记录。
- `alerts.yml`：玩家个人提醒开关。
- `backups/`：管理员手动备份生成的绑定数据库、旧版绑定数据、隔离记录、消息配置、提醒偏好和配置副本。

## 发布前测试建议

1. 绑定主手中数量为 1 的物品。
2. 测试从自己背包、他人背包、容器、掉落物、铁砧输入槽、展示框和盔甲架召回绑定物。
3. 测试丢失召回的余额不足、扣费成功和背包已满情况。
4. 测试不可离包：丢弃、放入容器、放入展示框、放到盔甲架以及死亡掉落。
5. 人为复制绑定 NBT，确认重复物会进入隔离仓库。
6. 在 GUI 管理员控制台点击“重载配置”后，确认 `messages.yml` 和 `config.yml` 生效。

## 安全说明

插件不会在无法确认原物品已移除时直接生成副本。若物品可能位于玩家临时界面或背包同步流程中，召回会优先失败并提示稍后重试，以避免恶性复制问题。
